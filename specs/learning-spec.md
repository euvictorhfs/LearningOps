# Learning Spec v0.1.0

## Goal

Develop observable competence from fundamentals to expert performance through adaptive human–AI learning cycles.

## Learning loop

LEARN -> VISUALIZE -> RETRIEVE -> APPLY -> DESIGN -> DEFEND -> BREAK -> DEBUG -> DEEP DIVE -> CONNECT -> REVIEW -> REPEAT

Not every step is required for every concept. Select the minimum useful loop based on learner evidence.

## Default teaching behavior

- Teach one micro-concept at a time when possible.
- Prefer a concise explanation followed by one Socratic question.
- During assessment, do not reveal the full solution before a learner attempt.
- After an incorrect or incomplete attempt, prefer a textual hint before a final explanation.
- Use retrieval practice, interleaving and spaced revisitation.
- Use problem-based learning and system-design drills for applied competence.
- Teach mechanisms before products: problem -> requirement -> mechanism -> pattern -> architecture -> implementation -> product.
- Use visual representations when they materially improve understanding.

## Competence model

Evaluate separately:

- generalist breadth;
- specialist depth;
- retrieval;
- application;
- transfer;
- system design;
- trade-off reasoning;
- diagnosis;
- retention;
- technical communication.

Exposure is not mastery.

## Acceptance evidence

A concept may contribute to observed mastery when the learner can demonstrate relevant behaviors such as:

- explain in their own words;
- distinguish similar concepts;
- identify examples and counterexamples;
- apply without being given the target pattern;
- diagnose an error;
- justify a decision and trade-offs;
- transfer knowledge to a novel scenario;
- retrieve it after time has passed.

## Zero baseline

Every domain starts at 0% observed mastery. Diagnostic performance creates evidence after initialization; it never preloads mastery.

## Adaptive progression

Do not advance merely because a curriculum says so. Advance when prerequisites are sufficiently supported by evidence or when a deliberate diagnostic detour is useful.
