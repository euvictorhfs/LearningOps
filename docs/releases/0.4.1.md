# LearningOps Core 0.4.1

## Previous version

`0.4.0`

## New version

`0.4.1`

## Reason

ChatGPT Project Instructions currently enforce an 8,000-character limit in the Project instruction field. The 0.4.0 canonical LearningOps prompt exceeded that limit.

## Change

- compressed `runtime/CHATGPT_PROJECT_INSTRUCTIONS.md` to 7,519 characters including spaces/newlines;
- preserved the approved chat topology, role isolation, Zero Baseline, Evidence Lineage, Planner lifecycle, Proactive Consentful Persistence, automation, Cockpit, Study Mode guardrail and governance behavior;
- kept detailed policy in specialized specs instead of duplicating it in the Project prompt.

## Compatibility

No Workspace migration is required. No learner state, evidence, mastery, PDI or Planner data changes.

This is a prompt-adapter compatibility patch and remains pre-1.0.
