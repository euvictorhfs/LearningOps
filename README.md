# LearningOps Core

Control plane, specifications, schemas and reusable engine for deliberate learning and evidence-based professional development.

LearningOps is responsible for:

- study sessions and curricula;
- zero-baseline observed mastery;
- validation and lineage of evidence;
- knowledge graph, gaps, misconceptions and PDI;
- longitudinal technical repertoire, positioning and metacognition;
- evidence-based résumé construction;
- the Learning Cockpit.

ThoughtOps remains responsible for producing daily work artifacts and may submit work-evidence candidates. It does not update mastery or maintain the longitudinal profile. See [specs/thoughtops-evidence-contract.md](specs/thoughtops-evidence-contract.md).

## ChatGPT Project setup

To create or reset the LearningOps Control Plane in ChatGPT, use the canonical project instruction:

- [runtime/CHATGPT_PROJECT_INSTRUCTIONS.md](runtime/CHATGPT_PROJECT_INSTRUCTIONS.md)

Canonical repositories:

- Core: https://github.com/euvictorhfs/LearningOps
- Workspace: https://github.com/euvictorhfs/LearningOps-workspace

The project instruction requires ChatGPT to validate actual GitHub access before relying on repository state. A repository link alone does not prove that the integration can read or write it.

> GitHub `main` is the durable source of truth. Architectural changes are governed through pull requests.
